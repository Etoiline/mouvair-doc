# Périmètre de la première version

Étape 3 — Validée le 6 septembre 2026. Complétée par les décisions sur les trois notes et l’information pollen du 7 septembre 2026.

Ce périmètre est présent dans la version locale vérifiée le 9 septembre 2026.

## Fonctionnalités incluses

- **Recherche par ville** : sélectionner la ville dont on souhaite consulter les conditions.
- **Quatre activités** : course tranquille, course intense, vélo et marche, pour une sortie de 1 h.
- **Prévisions sur les prochaines 24 heures** : consulter les conditions heure par heure, avec des horaires locaux clairement affichés.
- **Notes** : une note météo adaptée à l’activité avec trois sous-notes, une note qualité de l’air commune aux activités et une note globale, toutes sur 100.
- **Pollen** : types et concentrations prévus, affichés séparément, sans effet sur les notes en première version. Aucun niveau qualitatif pollen n’est affiché ; les valeurs absentes sont signalées.
- **Explications** : comprendre les facteurs qui pénalisent chaque créneau.
- **Meilleur créneau** : repérer l’heure la mieux notée pour l’activité choisie. Si tous les créneaux sont défavorables, le signaler explicitement.
- **Fiabilité des informations** : afficher l’heure de dernière récupération réussie, renouveler les prévisions et signaler les données manquantes.
- **Interface mobile et ordinateur** : permettre la consultation sur les deux formats.

## Hors périmètre

- Comptes utilisateurs et sauvegarde de préférences.
- Notifications et alertes envoyées automatiquement ; les messages météo affichés dans l’application sont inclus.
- Géolocalisation automatique.
- Itinéraires et conditions le long d’un parcours.
- Durée de sortie personnalisable.
- Personnalisation selon la santé ou la condition physique.

Ces fonctionnalités pourront être discutées plus tard, sans engagement à les développer.
